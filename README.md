# Einfach Software

Infoseite von Einfach Software (in Gründung): Gründer, Datenschutzhinweis für Interessenten, Datenschutzerklärung, Impressum, AGB und Abmelden.

- Quelltext: `src/page.html`
- Bauen: `python3 build.py` schreibt die öffentliche Seite nach `docs/` (GitHub Pages) und eine Vorschau nach `dist/`
- Kurze Adressen für E-Mails: `/datenschutz`, `/impressum`, `/agb`, `/abmelden`
